# sQratch Cleaner

[![All Contributors](https://img.shields.io/badge/all_contributors-2-orange.svg?style=flat-square)](#contributors-)
<!-- ALL-CONTRIBUTORS-BADGE:END -->

Sometimes you need to strip formatting from text. Like, you copied something out of a web page and need to edit it in a word processor and there are fonts and bolding and tables and all kinds of annoying goop. This repo is a web page that insta-cleans text.

1. Copy some formatted text to clipboard
2. Go to [sQratch.us](https://sqratch.us), where this app is hosted
3. Go to wherever you want to use the cleaned-up text
4. Paste

## Installation

<pre>git clone https://github.com/lucasgonze/sQratch
git submodule update --init --recursive</pre>


The [Libre Baskerville font](https://github.com/impallari/Libre-Baskerville) in
the hello-css fonts directory is distributed under [the SIL Open Font License 1.1](https://scripts.sil.org/cms/scripts/page.php?item_id=OFL-FAQ_web). 

The fleurons in the &lt;hr&gt; element are exports from the Deja-Vu font, which
is in the public domain.
